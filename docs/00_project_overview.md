# 00. プロジェクト概要

## アプリ名（仮）

一口馬主向け資金管理Webサービス

正式名称は未定です。以下のような候補があります。

- Horse Asset Manager
- 一口資金帳
- 愛馬資金ノート
- Uma Wallet
- 一口キャッシュフロー

## 目的

一口馬主活動におけるお金の流れを、出資検討時点から引退・精算完了まで一元管理するWebサービスを作る。

## 解決したい課題

一口馬主では、以下のようなお金の動きが発生する。

- 出資金
- 分割払い
- 月額維持費
- クラブ会費
- 保険料
- 手数料
- 賞金分配
- 出走手当
- 返還金
- 売却代金
- 保険金
- 引退精算金

これらはクラブや馬ごとに分散して管理されがちで、次の問題が起きやすい。

- 毎月いくら支払うのか分かりにくい
- 出資頭数が増えると総額が把握しづらい
- 予算を超えて出資してしまう
- 入金や分配金がどの馬に紐づくか分かりにくい
- 馬ごとの本当の回収率が分かりにくい
- 引退後の精算状況が追いづらい

## 中心コンセプト

> 愛馬の戦績ではなく、出資のお金を管理する。

または、

> 一口馬主のための、未来まで見える資金管理。

## アプリの独自性

既存の競馬アプリは、出走予定、レース結果、獲得賞金、回収率などを中心にしていることが多い。

本アプリでは、以下を中心にする。

- 出資前の資金シミュレーション
- 将来の支出予定
- 月間・年間予算
- 予定支出と実績支出の照合
- 出資可能額
- 馬別資金台帳
- 引退・精算管理

## 実装しないこと

以下はアプリの方向性をぶらさないため、MVPでは実装しない。

- レース予想
- 馬券予想
- 血統分析
- 調教分析
- 馬体評価
- 推奨出資馬判定
- 獲得賞金予測
- レース結果の自動取得
- 競馬ニュース
- 出資者コミュニティ

## MVP対象環境

- Windows PC
- Google Chrome
- Microsoft Edge

スマホアプリやネイティブアプリは将来検討とする。
