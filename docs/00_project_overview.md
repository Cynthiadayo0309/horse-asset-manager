# 00. プロジェクト概要

## 1. サービス概要

Horse Asset Manager は、一口馬主活動における出資金、維持費、会費、保険料、分配金、精算金などの資金移動を、出資検討から引退・精算完了まで一元管理するWebサービスです。

本サービスは競馬予想アプリではありません。馬の能力評価や投資推奨ではなく、利用者自身が決めた出資方針を資金面から管理できることを中心価値とします。

> 中心価値: 過去の収支記録だけでなく、未来の支払い予定、予算超過、出資可能額を見える化する。

## 2. 背景と課題

一口馬主では、クラブ、馬、対象月、支払い種別が異なる資金移動を長期間管理する必要があります。表計算や請求書だけで管理すると、次の問題が生じます。

- 月ごとの負担額と今後の支払い予定が分かりにくい。
- 出資候補を追加した場合の予算影響を比較しにくい。
- 予定額と実績額の差、未登録の実績を見落としやすい。
- 馬別・クラブ別の累計支出、入金、回収率を追いにくい。
- 馬名変更や引退後の精算により、過去の収支との対応が曖昧になりやすい。
- クラブ帳票からの転記に時間がかかり、二重登録の危険がある。

## 3. 目標

### 3.1 利用者価値

- 今月と今後12か月の支出予定を確認できる。
- 年間・月間予算に対する実績と見込みを確認できる。
- 出資候補を追加した場合の初回、月額、初年度、期間合計の負担を確認できる。
- 馬別、クラブ別、カテゴリー別、月別に資金実績を確認できる。
- 引退後も精算完了まで資金履歴を追跡できる。

### 3.2 システム目標

- 全主要データを利用者単位で分離する。
- 金額を円単位の整数で扱い、集計元を明確にする。
- 予定と実績を別データとして保持し、照合可能にする。
- 定期予定の生成とPDF取込を冪等にする。
- 低コストなCloudflare構成でMVPを運用できるようにする。

## 4. 対象利用者

| 利用者 | 主な目的 | 主な利用場面 |
|---|---|---|
| 出資検討者 | 新規出資後の資金余力を確認する | 募集検討、予算設定、複数候補比較 |
| 一口馬主 | 支出・入金・予定・回収状況を管理する | 月次確認、帳票取込、収支登録 |
| 引退馬保有者 | 引退後の売却、保険、返還、最終維持費を管理する | 精算開始から精算完了まで |
| 開発・運用者 | 安全かつ低コストでサービスを提供する | デプロイ、監視、障害対応、監査 |

MVPに管理者向け業務画面は含めません。`admin` ロールは将来拡張用です。

## 5. MVPスコープ

### 5.1 対象

- Windows 10/11上のGoogle Chrome、Microsoft Edge
- 360px以上の画面幅に対応するWeb UI。ただし主要な設計・受入はPC利用を基準とする
- メール・パスワードによる簡易認証
- クラブ、カテゴリー、馬、出資、収支、予定、予算、精算の管理
- シミュレーション、分析、アプリ内通知、CSV出力
- 対応済みクラブ帳票のブラウザ内PDF解析
- Cloudflare Worker、D1、Cronを使うdev環境

### 5.2 対象外

- レース予想、馬券予想、調教分析、血統評価、馬体評価
- 推奨出資馬判定、獲得賞金予測
- レース結果や競馬ニュースの自動取得
- iOS、Android、Swiftなどのネイティブアプリ
- AI OCR、画像PDF、暗号化PDF、未対応レイアウトの自動読取
- 添付ファイル保存、Cloudflare R2、メール・ブラウザ通知
- 課金、一般向け本番公開、出資者コミュニティ

## 6. 成功指標

MVP受入時は、少なくとも次を満たすことを成功とします。

1. 新規利用者が登録、初期設定、馬登録、出資登録、収支登録まで完了できる。
2. 別利用者の馬・収支・予定へAPI経由でもアクセスできない。
3. 今月の実績支出、実績入金、予定支出、予算残額が一貫した定義で表示される。
4. 同一の定期ルール生成または同一PDF取込を繰り返しても重複明細が作られない。
5. 馬別台帳の金額とCSV出力の金額が同じ `cashflows` を集計元とする。
6. 馬の完全削除は馬名の完全一致確認がなければ実行できない。
7. ChromeとEdgeで主要操作を完了できる。

## 7. 重要な業務ルール

### BR-01 金額

金額はすべて円単位の安全な整数で保存・計算します。小数の円、浮動小数点での金額保存は行いません。

### BR-02 実績集計の正本

実績支出・実績入金の集計元は `cashflows` の `status=confirmed` だけです。予定額、出資契約額、精算予定額を同じ実績として重ねて加算しません。

### BR-03 回収率

- 馬代回収率 = 実績入金合計 ÷ 出資元本 × 100
- 総合回収率 = 実績入金合計 ÷ 実績支出合計 × 100
- 分母が0の場合は0%と断定せず「算出不可」とする
- 表示は小数第1位までとする

### BR-04 出資可能額

出資可能額 = `max(0, 年間予算 - 実績支出 - 未払い予定支出)` とします。これは将来の利益や賞金を予測する値ではありません。

### BR-05 馬ステータス

馬ステータスは利用者が整理のために付けるラベルです。任意の状態へ直接変更でき、変更だけでは出資、収支、予定、精算を自動作成・変更しません。

### BR-06 馬名変更

現在名は `horses.name`、以前の募集名・旧名は `horse_name_aliases` に保持します。収支は馬IDで関連付け、PDF取込時は現在名と旧名の両方を照合します。同一表記が複数馬へ一致する場合は自動選択しません。

### BR-07 削除

収支などの業務データは原則アーカイブします。例外として馬は、登録済み馬名の完全一致入力による明示確認後、関連データを物理削除します。復元機能はありません。匿名の削除件数監査だけを残します。

### BR-08 PDF取込

PDF本体と抽出全文はブラウザ外へ送信しません。ブラウザで解析・確認した明細だけをAPIへ送ります。同一利用者・同一SHA-256ハッシュのPDFは再登録できません。

## 8. 用語

| 用語 | 定義 |
|---|---|
| 候補馬 | 出資を検討中、申込中、見送り、落選などの馬 |
| 出資馬 | 出資情報が登録された馬。ステータスとは独立 |
| 予定 | 将来発生すると見込む支出または入金 |
| 実績 | 実際に発生し、`cashflows` に確定登録された支出または入金 |
| 照合 | 予定と実績を関連付け、差額と理由を管理すること |
| 出資元本 | `investments.committed_amount_yen` に保持する契約上の出資額 |
| 精算 | 引退後の最終維持費、売却、保険、返還などの処理 |
| 対象年月 | 集計上の月を表す `YYYY-MM`。実際の発生日とは別項目 |
