# 05. 画面・ルーティング設計

## UI基本方針

Windows Web版を中心としつつ、360px以上のスマートフォン、タブレット、PCで主要操作を完了できるレスポンシブ構成にする。1024px以上では左サイドバー、1024px未満では上部ヘッダーと開閉式メニューを使用する。768px未満では一覧表をカード表示へ切り替える。

```text
┌──────────────┬──────────────────────────────┐
│ サイドメニュー │ メインコンテンツ              │
│              │                              │
│ ダッシュボード │ カード・表・グラフ・フォーム  │
│ 出資検討      │                              │
│ 出資馬管理    │                              │
│ 収支管理      │                              │
│ 支払予定      │                              │
│ 予算・資金計画│                              │
│ 分析          │                              │
│ 設定          │                              │
└──────────────┴──────────────────────────────┘
```

## ルーティング一覧

| パス | 画面 | 説明 |
|---|---|---|
| `/login` | ログイン | メール・パスワードログイン |
| `/setup` | 初期設定 | 年間予算、月間予算、クラブ、カテゴリー設定 |
| `/dashboard` | ダッシュボード | 今月の支出、入金、予算、アラート |
| `/prospects` | 出資検討一覧 | 検討中の馬一覧 |
| `/prospects/new` | 出資検討登録 | 検討馬登録 |
| `/prospects/:id` | 出資検討詳細 | 候補馬詳細、メモ、シミュレーション |
| `/simulations` | シミュレーション一覧 | 保存したシナリオ一覧 |
| `/simulations/:id` | シミュレーション詳細 | 複数候補の資金影響確認 |
| `/horses` | 出資馬一覧 | 出資中・引退・精算中の馬一覧 |
| `/horses/:id` | 馬詳細 | 基本情報、出資情報、資金台帳 |
| `/horses/:id/ledger` | 馬別資金台帳 | 馬ごとの支出・入金・回収率 |
| `/horses/:id/settlements` | 引退・精算管理 | 売却代金、保険金、最終精算など |
| `/cashflows` | 収支一覧 | 支出・入金の一覧 |
| `/cashflows/new` | 収支登録 | 実績支出・入金登録 |
| `/cashflows/import` | PDF取込 | シルク・ロードのPDFを予定または実績へ一括登録 |
| `/reconciliations` | 予定・実績照合 | 予定と実績の差額確認 |
| `/scheduled` | 予定支出一覧 | 今後の支出予定 |
| `/calendar` | 支払カレンダー | 支払予定をカレンダー表示 |
| `/budgets` | 予算・資金計画 | 月間・年間予算、出資可能額 |
| `/analytics` | 分析 | 馬別、クラブ別、カテゴリー別、月別分析 |
| `/settings/clubs` | クラブ設定 | クラブ登録・編集 |
| `/settings/categories` | カテゴリー設定 | 収支カテゴリー管理 |
| `/settings/alerts` | アラート設定 | 通知条件管理 |
| `/settings/export` | CSV出力 | データ出力 |

## ダッシュボード表示項目

### 上部カード

- 今月の予定支出
- 今月の実績支出
- 今月の入金
- 今月の差引
- 年間支出見込み
- 年間予算残額

### グラフ

- 直近6か月の予定支出と実績支出
- カテゴリー別支出
- クラブ別支出割合

### アラート

- 支払期限が近い予定
- 募集締切が近い候補馬
- 予算超過見込み
- 実績未登録の予定

## 出資検討画面

### 一覧

表示列：

- 馬名
- クラブ
- 募集年度
- 一口価格
- 予定口数
- 初回支払額
- 月額見込み
- 募集締切
- ステータス

### 詳細

タブ：

- 基本情報
- 出資条件
- 資金シミュレーション
- メモ
- 馬名・馬名カナの編集、以前の名前の表示

## 出資馬詳細画面

タブ：

- 基本情報
- 出資情報
- 資金台帳
- 予定支出
- 入出金履歴
- 回収率
- 引退・精算
- メモ

## 収支登録画面

入力項目：

- 種別：支出 / 入金
- 日付
- 対象年月
- 対象馬
- 対象クラブ
- カテゴリー
- 金額
- 予定支出との紐付け
- メモ

## PDF取込画面

「PDF選択 → 読取結果確認 → 紐付け設定 → 一括登録」の順に進める。帳票の支出・入金合計と登録対象明細の合計が一致し、馬・クラブ・カテゴリーの紐付けが確定するまで登録ボタンを有効にしない。PDF未選択・取込完了状態には資金管理用の馬シルエットを控えめに表示する。

## 分析画面

フィルター：

- 集計期間
- 馬
- クラブ
- カテゴリー
- 支出/入金

表示：

- 支出総額
- 入金総額
- 差引損益
- 馬代回収率
- 総合回収率
- 一覧表
- CSV出力ボタン
